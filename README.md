# Usage

```sh
make
```
At the root directory should always work.

## VSCode extension

With the VSCode extension you still need the `make` command to compile changes in the models (first and last pages).

But then you can simply `CTRL + S` on the chapter or main `.tex` files to recompile the whole pdf.

PS: don't hesitate to push a PR if you have a more pleasant way to compile this with the VSCode extension.
